# Local Exploratory Outputs

This folder contains small raw metrics from exploratory runs that were not part
of the supported Colab/T4 Week 2 transformer protocol.

Do not cite these files as the official Hugging Face token-classifier result.
The official transformer result should be produced from Google Colab with a T4
GPU runtime and metrics metadata that records CUDA device, package versions,
model name, training parameters, dataset split, and random seed.
