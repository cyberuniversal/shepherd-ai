# Drone State Datasets

This directory contains simulated drone-state inputs for scheduling experiments. These records are not physical-drone telemetry.

Current file:

- `week5_three_drone_fleet_v1.json`: three simulated Week 5 drones with starting map locations, availability times, speed proxies, and battery percentages. Battery is recorded as simulated state only; Week 5 does not enforce battery-threshold safety validation.
